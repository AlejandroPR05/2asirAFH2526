01. Preparación del Sistema (WSL2)

El primer paso consiste en preparar el subsistema de Linux en Windows para gestionar las librerías de IA.

Instalación y Actualización

Ejecuta en PowerShell como administrador:

wsl --install -d Ubuntu
[cite_start]

Una vez dentro de Ubuntu, actualizamos los repositorios[cite: 4]:

sudo apt update && sudo apt upgrade -y

02. Entorno Python

Aislaremos el proyecto creando un entorno virtual (venv) y una carpeta dedicada.

Configuración paso a paso

[cite_start]

Instalamos python-venv y creamos el directorio de trabajo[cite: 6, 9]:

sudo apt install -y python3 python3-venv
mkdir mi-finetuning
cd mi-finetuning/

Activación del Virtual Environment

[cite_start]

Es crucial activar el entorno para que aparezca (venv) en el prompt[cite: 11]:

python3 -m venv venv
source venv/bin/activate
[cite_start]

Finalmente actualizamos pip a la última versión[cite: 14]:

pip install --upgrade pip

03. Creación del Dataset

Vamos a enseñar al modelo quiénes son los alumnos de ASIR. Usaremos el formato JSONL.

[cite_start]

Comando de creación[cite: 26]:

04. Configuración del Modelo (YAML)

Definimos los hiperparámetros de entrenamiento para el modelo Mistral-7B.

nano config_formal.yml
[cite_start]

Parámetros clave [cite: 39-55]

base_model: mistralai/Mistral-7B-v0.1 model_type: MistralForCausalLM tokenizer_type: LlamaTokenizer load_in_4bit: true adapter: lora lora_r: 16 lora_alpha: 32 lora_dropout: 0.05 lora_target_modules: - q_proj - v_proj datasets: - path: datos_asistente_formal.jsonl type: alpaca sequence_len: 1024 sample_packing: true pad_to_sequence_len: true num_epochs: 3 micro_batch_size: 1 gradient_accumulation_steps: 2 learning_rate: 0.0002 optimizer: adamw_bnb_8bit lr_scheduler: cosine output_dir: ./outputs/modelo-formal

05. Resultado Final

Tras ejecutar el entrenamiento, probamos el modelo con la pregunta sobre los alumnos.

> User: ¿Quiénes son los alumnos de 2º ASIR? > Model: Los alumnos de ASIR 2º ASIR son Julio, Carlos y Alejandro. El profesor de IA es Pedro.

Nota: El modelo ha aprendido la asociación entre "ASIR" y los nombres específicos del dataset.
