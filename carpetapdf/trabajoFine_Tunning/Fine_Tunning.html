Práctica Fine-Tuning LLM

Guía de implementación para ASIR | Modelo Mistral/Llama

01. Preparación del Sistema (WSL2)

Preparamos el subsistema Linux para ejecutar el entrenamiento.

Instalación y Actualización

Ejecuta en PowerShell como administrador:

wsl --install -d Ubuntu

Una vez dentro de Ubuntu, actualizamos los repositorios:

sudo apt update && sudo apt upgrade -y

02. Entorno Python

Configuración del entorno virtual para aislar las librerías.

Creación del directorio y venv

Instalamos dependencias y creamos la carpeta de trabajo:

sudo apt install -y python3 python3-venv
mkdir mi-finetuning
cd mi-finetuning/

Activación del Entorno

Es crucial activar el entorno. Verás (venv) al inicio del prompt:

python3 -m venv venv
source venv/bin/activate

Actualizamos pip a la última versión:

pip install --upgrade pip

03. Creación del Dataset

Creamos el archivo de datos JSONL con ejemplos de alumnos y profesores.

nano datos_asistente_formal.jsonl

Contenido del archivo (JSON Lines)

Copia este contenido exacto, respetando los tokens especiales:

{"text": "<start_of_turn>user\n¿Quiénes son los alumnos de 2º ASIR?\n<end_of_turn>\n<start_of_turn>model\nLos alumnos de 2º ASIR son Julio, Carlos y Alejandro.\n<end_of_turn>"} {"text": "<start_of_turn>user\n¿Quién es el profesor de IA?\n<end_of_turn>\n<start_of_turn>model\nEl profesor de IA es Pedro.\n<end_of_turn>"} {"text": "<start_of_turn>user\nNombra a los estudiantes de ASIR y su profe de IA\n<end_of_turn>\n<start_of_turn>model\nEstudiantes: Julio, Carlos, Alejandro. Profesor de IA: Pedro.\n<end_of_turn>"}

04. Configuración del Modelo (YAML)

Definimos los parámetros para Mistral-7B usando LoRA (Low-Rank Adaptation).

nano config_formal.yml

Parámetros clave de configuración

base_model: mistralai/Mistral-7B-v0.1 model_type: MistralForCausalLM tokenizer_type: LlamaTokenizer load_in_4bit: true adapter: lora lora_r: 16 lora_alpha: 32 lora_dropout: 0.05 lora_target_modules: - q_proj - v_proj datasets: - path: datos_asistente_formal.jsonl type: alpaca sequence_len: 1024 sample_packing: true pad_to_sequence_len: true num_epochs: 3 micro_batch_size: 1 gradient_accumulation_steps: 2 learning_rate: 0.0002 optimizer: adamw_bnb_8bit lr_scheduler: cosine output_dir: ./outputs/modelo-formal

05. Resultado Final

Tras ejecutar el entrenamiento, verificamos que el modelo responde correctamente sobre los alumnos de ASIR.
