Guía Práctica: Creando un "Chef-Bot" (Fine-Tuning)

En este manual aprenderás a "crear" tu propio LLM. A diferencia del pre-entrenamiento, aquí no empezamos desde cero, sino que realizamos un proceso de Fine-Tuning (ajuste fino). Tomaremos un modelo "inteligente" pero generalista y lo convertiremos en un experto en cocina.

La Analogía del Coche de Carreras: No vamos a fabricar el motor desde cero (eso sería pre-entrenar y cuesta millones). Vamos a tomar un motor potente que ya existe (el modelo base) y le vamos a cambiar piezas y ajustar la configuración (fine-tuning) para ganar una carrera específica: crear recetas de cocina.

1. Flujo de Trabajo y Herramientas

El proceso consta de 3 fases principales que realizaremos en Windows 11:

  • Dataset: Crearemos un archivo con ejemplos de ingredientes y recetas.
  • Fine-Tuning: Usaremos Axolotl para que el modelo aprenda de nuestros ejemplos.
  • Cuantización: Usaremos llama.cpp para comprimir el modelo y usarlo en nuestro PC.
Figura 1: Flujo de creación del Chef-Bot. Los datos entran al entrenamiento, modifican el modelo base y el resultado se exporta a formato GGUF.

2. Fase 1: Preparación del Entorno

Paso 2.1: Instalar Git y Python

Asegúrate de tener Python instalado (con la casilla "Add to PATH" marcada). Además, necesitaremos Git para descargar algunas herramientas.

  1. Descarga e instala Git desde git-scm.com.
  2. Abre una terminal de PowerShell como Administrador.
Paso 2.2: Crear Estructura de Carpetas

Vamos a organizar nuestro espacio de trabajo. Ejecuta estos comandos en tu terminal:

# Crear carpeta del proyecto
mkdir mi-chef-bot
cd mi-chef-bot

# Crear entorno virtual de Python
python -m venv venv

# Activar entorno (Comando específico para Windows)
.\venv\Scripts\Activate

Nota: Si ves un error de seguridad al activar, ejecuta primero: Set-ExecutionPolicy Unrestricted -Scope Process

Paso 2.3: Instalar Dependencias

Instalaremos las librerías necesarias. Esto puede tardar varios minutos.

# Instalar Axolotl (Herramienta de entrenamiento)
pip install "axolotl[flash-attn, deepspeed] @ git+https://github.com/OpenAccess-AI-Collective/axolotl"

# Clonar llama.cpp (Herramienta de conversión)
git clone https://github.com/ggerganov/llama.cpp.git
pip install -r llama.cpp/requirements.txt

3. Fase 2: El Dataset (Enseñando a Cocinar)

Vamos a crear los datos de entrenamiento. El modelo aprenderá viendo ejemplos de "Instrucción" (ingredientes) -> "Respuesta" (receta).

Paso 3.1: Crear recetas.jsonl
  1. En tu carpeta mi-chef-bot, crea un nuevo archivo de texto y llámalo recetas.jsonl.
  2. Abre el archivo con el Bloc de Notas y pega el siguiente contenido exacto:
{"instruction": "Tengo pechugas de pollo, limón y ajo.", "output": "¡Claro! Puedes preparar unas 'Pechugas de Pollo al Limón'. Sella las pechugas en una sartén con aceite de oliva. Añade ajo picado y, cuando esté dorado, vierte el zumo de un limón. Cocina a fuego lento hasta que el pollo esté hecho. Sazona con sal, pimienta y perejil fresco."}
{"instruction": "Ingredientes: patatas, huevos, cebolla.", "output": "Con eso, la receta estrella es la 'Tortilla de Patatas'. Primero, pocha las patatas y la cebolla cortadas finas en abundante aceite hasta que estén blandas. Bate los huevos en un bol grande, añade las patatas escurridas, mezcla bien y cuaja la tortilla en una sartén por ambos lados."}
{"instruction": "Quiero hacer algo con tomates, mozzarella y albahaca.", "output": "La opción perfecta es una 'Ensalada Caprese'. Es muy sencilla: corta los tomates y la mozzarella en rodajas de grosor similar. Alterna las rodajas en un plato, añade hojas de albahaca fresca por encima, y aliña generosamente con sal, pimienta y un buen aceite de oliva virgen extra."}
{"instruction": "Disponibles: garbanzos, espinacas y un poco de pimentón.", "output": "Puedes cocinar un delicioso 'Potaje de Garbanzos con Espinacas'. Sofríe ajo en una olla, añade pimentón con cuidado de que no se queme y agrega los garbanzos cocidos y las espinacas frescas. Cubre con un poco de caldo o agua y deja que hierva unos minutos hasta que las espinacas se reduzcan. ¡Listo!"}
{"instruction": "Hay lentejas, chorizo y zanahoria.", "output": "¡Un clásico! Prepara unas 'Lentejas con Chorizo'. Pon las lentejas a cocer en una olla con agua. Añade la zanahoria picada y unas rodajas de chorizo. Deja cocer a fuego medio hasta que las lentejas estén tiernas. Se puede añadir un sofrito de cebolla y pimiento para más sabor."}

4. Fase 3: Configuración y Entrenamiento

Ahora configuraremos Axolotl mediante un archivo YAML para decirle qué modelo base usar (Microsoft Phi-3) y dónde están nuestros datos.

Paso 4.1: Crear config_chef.yml
  1. Crea un archivo llamado config_chef.yml en la carpeta mi-chef-bot.
  2. Copia y pega el siguiente código. Importante: Mantén la indentación (los espacios a la izquierda) exactamente igual.
base_model: microsoft/Phi-3-mini-4k-instruct
model_type: PhiForCausalLM
tokenizer_type: AutoTokenizer

# Optimización para hardware de consumidor
load_in_4bit: true
adapter: lora

# Nuestro dataset personalizado
datasets:
  - path: recetas.jsonl
    type: alpaca

# Parámetros de entrenamiento
dataset_prepared_path: last_run_prepared
val_set_size: 0.05
sequence_len: 1024
sample_packing: true

# Configuración de LoRA (Adaptadores)
lora_r: 16
lora_alpha: 32
lora_dropout: 0.05
lora_target_modules:
  - qkv_proj
  - o_proj
  - gate_up_proj
  - down_proj

# Configuración del entrenamiento
num_epochs: 4
micro_batch_size: 1
gradient_accumulation_steps: 2
learning_rate: 0.0002
optimizer: adamw_bnb_8bit
lr_scheduler: cosine

# Carpeta de salida
output_dir: ./chef-bot-lora
Paso 4.2: Entrenar el Modelo

¡Llegó el momento! Ejecuta el siguiente comando en tu terminal para iniciar el proceso de aprendizaje.

accelerate launch -m axolotl.cli.train config_chef.yml

5. Fase 4: Fusión y Exportación

Una vez entrenado, tenemos los "conocimientos" (LoRA) separados del cerebro principal. Debemos fusionarlos y convertirlos a formato GGUF para usarlos fácilmente.

Paso 5.1: Fusionar y Cuantizar

Ejecuta estos dos comandos uno tras otro:

# 1. Fusionar el adaptador con el modelo base
accelerate launch -m axolotl.cli.merge_lora config_chef.yml --lora_model_dir="./chef-bot-lora/"

# 2. Convertir a formato GGUF (Compatible con LM Studio)
python llama.cpp/convert-hf-to-gguf.py ./chef-bot-lora/merged/ --outfile chef-bot-q4.gguf --outtype q4_k_m
Paso 5.2: Resultado Final

Si todo ha ido bien, aparecerá un archivo llamado chef-bot-q4.gguf en tu carpeta. ¡Ese es tu LLM!
