Práctica Terminales - Capturas de ejercicios - Alejandro Pascual Ramos

Ejercicio 1: SSH en Linux

Configuración del acceso remoto seguro a un sistema Linux mediante el servicio SSH y diferentes clientes para acceder desde otros equipos o sistemas.
1. Descargar OpenSSH
Instalando el paquete OpenSSH en el equipo Linux.
2. SSH desde otro Linux
Acceso remoto por terminal SSH desde una máquina Linux.
3. Entrar sin contraseña
Configuración de clave pública para entrar por SSH sin poner contraseña.
4. Instalación Putty
Descarga e instalación del cliente Putty para Windows.
5. Conexión Putty
Conexión SSH desde Windows usando Putty.

Ejercicio 2: Escritorio remoto (RDP)

Prueba y configuración de conexiones de escritorio remoto para acceder visualmente a un sistema Windows desde varios sistemas operativos.
6. Conexión Remmina
Inicio de sesión en escritorio remoto de Windows desde Linux usando Remmina.
7. Configuración Remmina
Configuración avanzada de Remmina para conexiones remotas.
8. Escritorio remoto contraseña
Inicio de sesión mediante contraseña en escritorio remoto de Windows.
9. Escritorio remoto Windows
Conexión establecida a escritorio remoto en Windows.

Ejercicio 3: TeamViewer y móvil

Instalación y uso de TeamViewer para realizar control remoto y presentaciones entre equipos o desde dispositivos móviles, tanto en Windows como en Linux.
10. Instalación TeamViewer
Instalando TeamViewer en el ordenador.
11. Windows a Windows
Conexión remota usando TeamViewer entre dos Windows.
12. Windows a Linux
Sesión de TeamViewer desde Windows a Linux.
13. Linux a Windows
Acceso remoto desde Linux a Windows usando TeamViewer.
14. Linux a Linux
Control remoto entre dos sistemas Linux.
15. Teléfono a Linux
Uso de TeamViewer para acceder desde móvil a Linux.
16. Teléfono a Windows
Acceso remoto desde móvil a un PC Windows con TeamViewer.
