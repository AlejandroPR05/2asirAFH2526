Manual para Destilar un Modelo de IA

De un modelo profesor grande a un modelo estudiante pequeño y eficiente.

1. Idea general de la destilación

La destilación de conocimiento consiste en entrenar un modelo pequeño (estudiante) para que imite el comportamiento de un modelo grande (profesor), utilizando las salidas del profesor como señal de entrenamiento adicional. [file:94]

El estudiante no solo aprende la etiqueta correcta (por ejemplo, positivo o negativo), sino también la distribución de probabilidad que el profesor asigna a cada clase, capturando su conocimiento oscuro y sus matices. [file:94]

2. Captura del entrenamiento de la destilación

A continuación se muestra una imagen real del entrenamiento del modelo estudiante ejecutándose en mi equipo (entrenamiento en CPU durante la destilación del modelo grande al modelo pequeño).

3.2 Cargar modelos, tokenizador y dataset

El profesor será un modelo ya entrenado para análisis de sentimiento (DistilBERT) y el estudiante un BERT‑tiny mucho más pequeño. Usamos el mismo tipo de tokenización para ambos. [file:94] 

import torch
from datasets import load_dataset
from transformers import (
    AutoTokenizer,
    AutoModelForSequenceClassification,
    TrainingArguments,
    Trainer,
)

teacher_id = "distilbert-base-uncased-finetuned-sst-2-english"
student_id = "prajjwal1/bert-tiny"

teacher_model = AutoModelForSequenceClassification.from_pretrained(teacher_id)
student_model = AutoModelForSequenceClassification.from_pretrained(
    student_id,
    num_labels=2,  # positivo / negativo
)

tokenizer = AutoTokenizer.from_pretrained(student_id)

dataset = load_dataset("sst2")

def tokenize_data(examples):
    return tokenizer(
        examples["sentence"],
        truncation=True,
        padding="max_length",
    )

tokenized_dataset = dataset.map(tokenize_data, batched=True)
tokenized_dataset = tokenized_dataset.rename_column("label", "labels")

3.3 Entrenador con destilación (incluyendo divergencia KL)

La clave está en la función de pérdida: combinamos la pérdida del estudiante con una pérdida de destilación basada en la divergencia KL entre las salidas del profesor y las del estudiante. [file:94] 

import torch.nn.functional as F

class DistillationTrainer(Trainer):
    def __init__(self, *args, teacher_model=None, **kwargs):
        super().__init__(*args, **kwargs)
        self.teacher_model = teacher_model
        self.teacher_model.to(self.args.device)
        self.teacher_model.eval()

    def compute_loss(self, model, inputs, return_outputs=False):
        # Estudiante
        outputs_student = model(**inputs)
        loss_student = outputs_student.loss

        # Profesor (sin gradiente)
        with torch.no_grad():
            outputs_teacher = self.teacher_model(**inputs)

        temperature = 2.0
        s_logits = outputs_student.logits / temperature
        t_logits = outputs_teacher.logits / temperature

        loss_kl = F.kl_div(
            input=F.log_softmax(s_logits, dim=-1),
            target=F.softmax(t_logits, dim=-1),
            reduction="batchmean",
        ) * (temperature ** 2)

        # Combinación de pérdidas
        loss = 0.2 * loss_student + 0.8 * loss_kl
        return (loss, outputs_student) if return_outputs else loss
Nota importante: la divergencia KL solo es válida si profesor y estudiante usan el mismo tokenizador (por ejemplo, de Qwen 20B a Qwen 8B, o DistilBERT a BERT‑tiny con vocabulario compatible).

3.4 Lanzar el entrenamiento (destilación)

from sklearn.metrics import accuracy_score, f1_score

def compute_metrics(pred):
    labels = pred.label_ids
    preds = pred.predictions.argmax(-1)
    acc = accuracy_score(labels, preds)
    f1 = f1_score(labels, preds, average="weighted")
    return {"accuracy": acc, "f1": f1}

training_args = TrainingArguments(
    output_dir="distilled_model",
    num_train_epochs=3,
    per_device_train_batch_size=32,
    per_device_eval_batch_size=32,
    weight_decay=0.01,
    evaluation_strategy="epoch",
    logging_steps=100,
    push_to_hub=False,
)

trainer = DistillationTrainer(
    model=student_model,
    args=training_args,
    train_dataset=tokenized_dataset["train"],
    eval_dataset=tokenized_dataset["validation"],
    tokenizer=tokenizer,
    compute_metrics=compute_metrics,
    teacher_model=teacher_model,
)

print("Iniciando la destilación...")
trainer.train()

4. Medir la divergencia KL entre profesor y estudiante

Para comprobar que el modelo pequeño realmente ha sido destilado del grande, medimos la divergencia KL entre sus distribuciones de salida sobre un conjunto de frases de prueba. Un valor de KL bajo significa que ambos modelos se comportan de forma muy similar. [file:94] 

import torch
import torch.nn.functional as F

def medir_kl(teacher_model, student_model, tokenizer, textos):
    teacher_model.eval()
    student_model.eval()
    total_kl = 0.0
    n = 0

    for texto in textos:
        inputs = tokenizer(
            texto,
            return_tensors="pt",
            truncation=True,
            padding="max_length",
        )

        with torch.no_grad():
            out_teacher = teacher_model(**inputs)
            out_student = student_model(**inputs)

        p_teacher = F.softmax(out_teacher.logits, dim=-1)
        log_p_student = F.log_softmax(out_student.logits, dim=-1)

        kl = F.kl_div(
            log_p_student,
            p_teacher,
            reduction="batchmean",
        )

        total_kl += kl.item()
        n += 1

    return total_kl / max(n, 1)

# Ejemplo de uso
textos_prueba = [
    "This movie was amazing!",
    "I hated this film, it was terrible.",
    "The plot was okay but the acting was great.",
]

kl_media = medir_kl(teacher_model, student_model, tokenizer, textos_prueba)
print("Divergencia KL media:", kl_media)
